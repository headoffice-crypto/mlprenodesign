Conseils d'impression

  • Format papier : 3,5 × 2 po (88,9 × 50,8 mm) — standard nord-américain.
  • Pour un meilleur rendu, imprimez sur papier mat 300 g/m² ou plus.
  • Activez « Imprimer les arrière-plans / les couleurs » dans la fenêtre d'impression du navigateur.
  • Le code QR fonctionne avec l'appareil photo natif (iPhone, Android). Tester avant de tirer en quantité.
